# EcoEnergy

Sistema de monitoramento de consumo energético.

## Tecnologias

- Java 17
- Spring Boot
- Oracle Database
- Flyway
- Swagger
- HTML/CSS/JS

## Como executar

```bash
mvn spring-boot:run
```

## Swagger

http://localhost:8080/swagger-ui/index.html

## Funcionalidades

- Cadastro de equipamentos
- Controle de consumo
- Alertas energéticos
